Copperplate

Any image, printed as an engraved metal plate that catches the light. Its own brightness becomes the depth of the cut, and one lamp lights every plate on the page.

Move the pointer over the plates.

Six metals

Each preset is three colours: the shadow in the deepest line, the highlight on the raised ground, and the sheen of the glint. Pass your own for anything else.

Playground


      


      

        
Usage

        
npm install copperplate

        

          

            
Vanilla


import { engrave } from 'copperplate';

const plate = engrave('#portrait', {
  src: '/knight.jpg',
  alt: 'Dürer, Knight, Death and the Devil',
  material: 'copper',
});

plate.update({ relief: 4 });
plate.destroy();

          

          

            
React


import { Engraving } from 'copperplate/react';

<Engraving
  src="/knight.jpg"
  alt="Dürer, Knight, Death and the Devil"
  material="brass"
  style={{ width: 320, aspectRatio: '1' }}
/>
